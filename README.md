# CodeAlpha_Calculator
# ✦ WispCalc — Magical Calculator

A creative and interactive calculator built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Web Development Internship – Task 2**.

WispCalc combines a functional calculator with a cute magical "wisp" theme, animated doodles, a modern glassmorphism interface, theme switching, and keyboard support.

---

### What I Was Asked to Do

Create a basic calculator using **HTML, CSS, and JavaScript**.

The calculator should:

- Perform basic arithmetic operations
- Include buttons and a display screen
- Handle user input
- Clear the calculator screen
- Display results in real time
- Support additional styling enhancements
- Bonus: Add keyboard support

---

## 💡 What I Did

Instead of creating a simple traditional calculator, I designed **WispCalc**, a magical and interactive calculator with a unique visual identity.

The calculator includes:

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- % Percentage
- ⌫ Backspace
- AC Clear
- Decimal calculations
- ⌨️ Keyboard support
- ☾ Dark/Light theme toggle
- ✨ Animated magical doodles
- 👻 Wisp-inspired design
- 📱 Responsive mobile layout
- ⚡ Interactive button animations
- 🚫 Division-by-zero error handling

---

## ✨ Creative Features

### 👻 Wisp Theme

The calculator is designed around a cute magical "Wisp" concept with:

- Ghost-inspired logo
- Floating ghost emojis
- Stars and moons
- Mathematical symbols
- Handwritten equations
- Sparkles and magical doodles

### 🌙 Theme Toggle

Users can switch between:

- Dark magical mode
- Light magical mode

by clicking the theme button.

### ⌨️ Keyboard Support

The calculator can also be controlled using the keyboard.

Supported keys include:

| Key         | Function       |
|-------------|----------------|
| `0 - 9`     | Numbers        |
| `+`         | Addition       |
| `-`         | Subtraction    |
| `*`         | Multiplication |
| `/`         | Division       |
| `%`         | Percentage     |
| `.`         | Decimal        |
| `Enter`     | Calculate      |
| `=`         | Calculate      |
| `Backspace` | Delete         |
| `Escape`    | Clear          |
